# 🐾 Cute Asset Checking Web Application

เว็บแอปพลิเคชันสำหรับตรวจสอบและยันยอดทรัพย์สินระหว่างฐานข้อมูลสินทรัพย์กับบัญชี ในธีมน่ารัก พาสเทล อ่านง่าย ใช้งานสะดวก

## 🌟 ฟีเจอร์หลัก (Features)
- 📊 **Dashboard สรุปภาพรวม**: แสดงจำนวนรายการที่ยอดตรง / ไม่ตรงกันทันที
- 🔍 **ระบบ ค้นหา (Search)**: ค้นหาชื่อหน่วยงานหรือรายการครุภัณฑ์แบบ Real-time
- 🎯 **ตัวกรอง (Filter)**: กรองดูเฉพาะรายการที่มีปัญหาได้ด้วยคลิกเดียว
- ✅ **Interactive Checkbox**: ติ๊กถูกเพื่อบันทึกการเช็กรายการได้ง่ายๆ

## 🚀 วิธีเปิดใช้งานออนไลน์ด้วย GitHub Pages
1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. ไปที่เมนู **Pages** (เมนูด้านซ้าย)
3. ในส่วน **Branch** เลือก `main` หรือ `master` แล้วกด **Save**
4. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์สำหรับเข้าใช้งานได้ทันที!
